# Portfolio Backend API

API backend em TypeScript com autenticação, usuários e posts, pensada para compor o portfólio de um desenvolvedor.

## Funcionalidades
- Estrutura modular para rotas e middlewares
- Autenticação com JWT
- Endpoint de status da API
- Configuração pronta para TypeScript e Node.js

## Como rodar
```bash
npm install
npm run build
npm start
```

## Desenvolvimento
```bash
npm run dev
```

## Observações
Este projeto foi organizado para parecer mais profissional e adequado para demonstração em GitHub e currículo.
